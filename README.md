# Student Performance Data Analysis

## About the Project
This beginner-friendly Data Science project uses Python to analyze fictional student marks and attendance data.

## Objectives
- Explore a structured dataset using Pandas.
- Calculate average, highest, and lowest marks.
- Compare student marks using a bar chart.
- Identify students meeting selected marks and attendance criteria.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Dataset
The dataset contains 10 fictional student records with marks and attendance percentages.

## Key Findings
- Average marks: 70.5
- Highest marks: 95
- Lowest marks: 39
- Average attendance: 83.3%

## Project Files
- `student_performance_analysis.ipynb` — Python analysis and outputs.
- `student_performance.csv` — Sample dataset.
- `student_marks.png` — Marks comparison chart.

## How to Run
1. Open the notebook in Google Colab.
2. Upload `student_performance.csv` if needed.
3. Run the cells in order.

## Limitations
This is a small fictional dataset for learning purposes. Its results should not be generalized to real students.
